最終更新: 2026-10-05。本書は出口工場パイロットの仕様を記載する(既存の収集基盤・評議会の経緯は HANDOFF.md / DECISIONS.md / GOVERNANCE.md を参照)。

1. 補助金パイロット(テーマP)

出口工場(一次情報の自動収集→AI構造化→ページ自動生成→アフィリエイト・広告)の国内向けパイロット1本目。現段階のゴールは「実データからローカルで静的ページを生成できること」。公開・アフィリエイトは対象外。

1.1 実行方法

コマンド動作
npm run pilot:subsidy収集 → AI分類(未分類のみ) → ページ生成
npm run pilot:subsidy -- --no-aiAI分類を省略(未分類のJ-Net21案件はページに出ない)
npm run pilot:subsidy -- --generate-only収集もせず保存済みデータからページだけ生成

どちらかの情報源の取得に失敗しても、もう一方の収集とページ生成は続行する。AI分類には ANTHROPIC_API_KEY(.env)が必要。

1.2 構成

ファイル(src/pilots/subsidy/)役割
run.tsエントリポイント。収集→分類→再正規化→保存→生成
collectJgrants.tsjGrants公開APIから受付中の案件を取得
collectJnet21.tsJ-Net21支援情報ヘッドラインRSSを取得・蓄積
classify.tsJ-Net21案件をHaiku 4.5で分類、和暦の日付換算、費用のledger記帳
taxonomy.ts分類表(都道府県・業種・目的)と正規化
generate.ts静的HTMLの生成
store.ts / types.tsJSONストアの読み書き / 案件の型

1.3 収集元

収集元取得方法規約・注意
jGrants公開API(デジタル庁)
api.jgrants-portal.go.jp/exp/v1/public		 一覧APIはキーワード2文字以上が必須で全件一括取得できないため、10語(補助・助成・支援・事業・交付・奨励・給付・促進・対策・推進)を受付中(acceptance=1)で検索し、IDで重複を除く。各案件は詳細APIを1秒間隔で取得。一覧の締切値が前回と同じ案件は詳細APIを呼ばない。 robots.txtは404(制限なし)。Web-API利用規約(fs2.jgrants-portal.go.jp/API利用規約.pdf、2026-10-05確認): 商用利用の禁止なし、出典「出典：Jグランツ」必須、編集・加工した場合は加工した旨と「政府・自治体の保証ではない」旨の記載が必須、短時間の大量アクセス・事実に反する内容は禁止、ベータ版のため予告なく停止しうる。詳細APIは添付PDFのbase64を含み重い。一覧と詳細で締切が食い違う案件があるため、表示には詳細側を使い、再取得の判定には一覧側を使う。
J-Net21 支援情報ヘッドラインRSS(中小機構)
j-net21.smrj.go.jp/snavi/support/support.xml		 RSSは最新数十件しか載らないため、取得のたびにストアへ蓄積する。都道府県は dc:coverage から、補助金/融資の別は dc:subject の「 - 」以降から判定する。 robots.txtは404。利用規約で事前承諾なき転載・再利用は禁止、リンクは自由(「出典：中小機構 J-Net21」必須)。本文はAI分類の入力にのみ使い、ページに出すのは制度名・地域・締切・リンク・出典だけにする。

通信はすべて既存の politeFetch(robots.txt確認、ホストごとの直列実行、5xx/429の指数バックオフ)を経由する。

1.4 分類

軸語彙jGrantsJ-Net21
地域47都道府県+全国APIの対象地域。地方ブロック名は構成都道府県に展開し、47都道府県すべてを含む場合は全国とするRSSの dc:coverage
業種日本標準産業分類の大分類19種(空=業種を問わない)APIの業種。16種以上を列挙した案件は「業種を問わない」とみなす。「分類不能の産業」は無視するAI
目的jGrantsの利用目的15種APIの利用目的AI(1〜3個)
締切日時APIAIは本文の表記のまま抜き出し、コードで西暦に換算する(年の書かれていない日付は掲載日以降で最も近い日付とする)
  • AIモデルは claude-haiku-4-5。構造化出力(JSONスキーマ、業種・目的はenumで制約)を使い、1リクエストで20件ずつ処理する。
  • 分類済みの案件は再分類しない。かかった費用は1回の実行につき1行として data/ledger.json に記帳する(費目api、service pilot-subsidy-haiku)。実績は64件で約$0.048(約8円)。
  • jGrantsは元の値(sourceFields)を保存しておき、毎回の実行で正規化し直す。分類表を直しても再取得は不要。
  • 語彙に無い値は捨てずに、実行終了時に一覧を表示する(分類表への追加漏れの検知用)。

1.5 データ保存

data/pilots/subsidy/items.json(git管理外)。パイロットの間はDBスキーマを変更しない。主な項目は id(source:元ID)、title、url、kind(grant/loan)、regions、industries、purposes、acceptanceEnd、classifiedBy(source/ai/pending)、firstSeenAt/lastSeenAt、sourceFields(jGrants)、rawText(J-Net21、ページには出さない)。

1.6 生成ページ

出力先は site/subsidy/(git管理外)。前回分が残らないよう、毎回いったん削除してから作り直す。リンクはすべて相対パスで、file:// で開いても辿れる。

パス内容生成条件
index.html地域・業種・目的の索引(件数付き)、新着30件常に生成
region/{pref}/index.htmlその地域限定の案件(全国対象は全国ページへ誘導)、目的別・業種×目的別の絞り込みリンク1件以上(全国は常に生成)
region/{pref}/p-{purpose}.html地域×目的1件以上
region/{pref}/{industry}/{purpose}.html地域×業種×目的。業種を問わない同条件の案件と、全国対象の同条件の案件を別の欄で併記業種を特定した案件が1件以上
industry/{industry}/index.html、industry/any/index.html業種別/業種を問わない1件以上
purpose/{purpose}/index.html目的別1件以上
  • 掲載対象は、締切が未来の案件と、締切不明のJ-Net21案件のうち掲載から60日以内のもの。未分類の案件は掲載しない。
  • 各案件には出典を表示する(「出典：Jグランツ」/「出典：中小機構 J-Net21」)。フッターには両方の出典と、jGrants利用規約第5条1項二の記載例に沿った加工表示(「このコンテンツは、政府公式の補助金申請システム jGrants の Web-API 機能を利用して取得した情報をもとに作成者名にて作成されたものです。コンテンツの内容は日本国政府及び自治体によって保証されたものではありません。」)を表示する。作成者名は公開時にオーナーが決めるまで「本サイト運営者」と仮置き(generate.tsのOPERATOR_NAME)。
  • リンク先は各出典の公式ページ(rel="nofollow noopener")。
  • 2026-10-05時点の実績: 820ページ(組み合わせ741)、掲載397件。
